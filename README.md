# candle-website

Aavé Candlès landing page built with Next.js, React, and TypeScript.

## Requirements

- Node.js 20.19 or newer
- npm

## Development

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run lint
npm run build
```
